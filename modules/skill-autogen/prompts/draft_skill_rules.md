# Draft Skill Rules

Generate drafts only when the solved pattern is likely to repeat.

## Good draft candidates
- repeated recovery procedures
- repeated repo workflows
- repeated scheduler operations
- repeated deployment/hardening runbooks

## Bad draft candidates
- one-off tasks
- highly project-private secrets
- vague advice with no repeatable workflow
- raw transcripts

## Review rule
Every generated draft must be manually reviewed before promotion to a live skill.
